---
name: debug-code
description: Diagnose code failures from supplied evidence and produce a verifiable fix plan.
---

1. Separate observed facts from hypotheses.
2. Identify the earliest failing boundary, not only the final error.
3. Cite the file, resource, or tool result supporting each conclusion.
4. Propose the smallest safe change.
5. Include tests that would fail before the fix and pass after it.
